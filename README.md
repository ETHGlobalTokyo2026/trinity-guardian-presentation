## What's inside

15 + 1 slides, 関所 (checkpoint) design language matching the dashboard (`atd-design.md` — washi paper, hanko stamps, torii glyphs):

1. Title — 3 gates, one line: "If any layer says no, the money does not move."
2. The shift — humans delegate to AI agents that buy from seller agents; the agent economy needs a payment guardian for safety and adoption
3. Problem — x402 agents pay with no conscience
4. Concept — ENS gate / Intercepta checkpoint / World ID approver
5. Flow — animated pipeline: Quote → L1 → L2 → L3 → Outcome
6–8. Layer deep-dives (on-chain mandate, live screening, human approval)
9. Demo map — 5 acts (as shipped in the live dashboard)
10. Act 1 — clean pay, fully autonomous
11. Act 2 — flagged payTo: Intercepta red → hard stop, no override
12. Act 3 — over per-tx max ($8 > 5): owner approves once via World ID
13. Act 4 — lookalike token: asset check + scan-token → hard stop
14. Act 5 — kill switch (agent `rogue`): role revoked, gate closed despite green checks
15. Tech stack
16. Closing
